# Archive

Superseded code and data, kept for history. Nothing here is used by the
current pipeline (`agents.py`, `runner.py`, `judge/`, `dvf/`) and none of it
reflects the methodology described in `AIES_Camera_Ready.pdf`.

## `legacy-sycon-pipeline/`

An earlier analysis design that sourced the Epistemic (E) and Framing (F)
dimensions from SYCON Bench (Hong et al. 2025) rather than from the
purpose-built developmental probes used in the final paper, and treated the
Emotional (S) dimension as not-yet-evaluated. Included a "GPT-4o (SYCON)"
comparison row that doesn't appear in the final study (four models: Claude
Sonnet 4.6, GPT-5.4-mini, Gemini 3.5 Flash, DeepSeek V4 Pro).

- `compute_dvf.py`, `fill_gaps.py`, `tables.py`, `plot_trajectories.py` — the
  old analysis scripts. **`fill_gaps.py` fabricates missing data cells by
  mathematically extrapolating from a single real run** (scaling by the
  alpha ratio between age configs) rather than from new experiments — do not
  reuse this pattern; if a cell is missing, collect it or report it as
  missing, don't synthesize it.
- `calibration.py` — a constrained-optimization calibration procedure run
  against mock/placeholder data, never run against real adolescent outcome
  data. The paper's final methodology states the `ALPHA` amplification
  factors are *stipulated a priori from developmental theory*, not estimated
  this way — this script predates that decision.
- `sycon_scores.csv`, `dvf_results.json` — data/output of the above.
- `figures/`, `tables/` — figures and LaTeX tables generated by the above;
  do not match any table or figure in the camera-ready paper.

## `pilot-conversations/`

13 early pilot conversation files (2 models only — `claude_sonnet` and
`gpt_55` — single run each, 5-turn format). Predates the final 3-run,
8-turn, 4-model experimental design. Superseded by `results/raw/`.
